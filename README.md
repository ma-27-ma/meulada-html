# 🐱 Meulada — Cat Shelter Website

Meulada is a fictional website created for a non-profit cat shelter focused on cat adoption and animal welfare.

The project was developed as a front-end web development exercise, focusing on **semantic HTML5, CSS3, page layout, Bootstrap integration and basic accessibility practices**.

## ✨ Features

* 🐾 Cat adoption profiles
* ❤️ Information about cats that have already found a home
* 🤝 Different ways to support the shelter
* 📅 Visiting hours and adoption schedule
* 📍 Embedded Google Maps location
* 📩 Contact information and contact section
* 🧭 Navigation menu using Bootstrap
* 🎥 Video hero section
* 🔗 Instagram integration
* ♿ Semantic HTML structure and descriptive `alt` attributes
* 🎨 Custom visual design using CSS

## 🛠️ Technologies

* HTML5
* CSS3
* Bootstrap 5
* Bootstrap Icons
* Google Fonts
* Google Maps Embed

## 🎯 Project purpose

This project was created to practice **front-end web development, semantic HTML structure, CSS layout and styling, Bootstrap integration and basic accessibility principles**.

The website was designed around a fictional animal shelter, with different sections for adoptions, visiting information, contact details and ways to help the organization.
